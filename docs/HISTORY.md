# Source lineage and result identity

- v0.4.0, commit afc2a4a054a57d34bf08fdb38c17662f725f0717: previous published
  final-test snapshot, using fraction50 and the earlier 594-task protocol.
- v0.4.9.dev1 and v0.4.10.dev1: separate development candidates and results.
  The latter added explained shared-product relations, resumable conflict
  subproblems and consistency-check budget reserve. Its reviewed LS comparison
  selected interleaved50 explicitly.
- v0.5.0: engineering promotion of that reviewed v0.4.10.dev1/interleaved50
  configuration, with the default, version locks, documentation and regression
  entry synchronized to the final external 576-task snapshot.

Old source snapshots and results remain archived under their original identity.
Changing the default is intentional but must not change the interpretation of
historical fraction50 records. This source release publishes no new benchmark
results and does not start the planned formal experiment.
