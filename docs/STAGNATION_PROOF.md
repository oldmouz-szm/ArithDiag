# Incumbent-first proof burst on an existing stagnation event

The same nonrenewing 50% cap applies. After native search has provided a current
validated incumbent and stops by its existing three-second stagnation rule,
unused proof credit may be advanced for one uninterrupted strengthening call.
This gives the lower-guided conflict master useful time after a candidate is available,
rather than before native search. It borrows remaining quota; it never creates
additional quota. Available-budget methods are restored on normal return and
exceptions. Borrowed time remains charged to the shared ledger and whole-worker
deadline. Native search has exited before this call, so no native pause clock is
charged. This is a scheduling heuristic, not an optimality assumption.
